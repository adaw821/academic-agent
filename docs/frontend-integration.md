# 前端功能接入与验证（2026-10-27）

## 已接入

- 研究项目：历史会话分页、完整消息恢复与继续追问、引用恢复、文档正文查看、原文件下载、失败重试、重新处理和删除确认。
- 后台任务：状态列表、未完成任务自动刷新、失败任务重试、打开已完成问答。问答区可选择后台问答，刷新后从任务列表找回。
- 学校助手：查询开关与两类操作授权分别控制；无文档项目可以查询学校数据。指定文档和选区仍优先文档问答。
- 学校事务：会话配置与解除、课程发现及不完整提示、课程链接导入和单课程同步、作业状态及日期筛选、附件下载缓存和导入项目、提醒筛选与已读。
- 课表：已保存课表读取、按日期查询与分页、学期起止、教学周范围和单双周规则设置与清除。图片识别后重新读取已保存记录。
- 新增组件均在离开页面后忽略迟到的结果或错误；历史消息另有项目/会话请求序号保护，登录过期会清空页面数据。
- 用户可见的日期时间显示为北京时间；学校链接仅允许 HTTP/HTTPS，Markdown 正文继续使用 DOMPurify。

## 验证

`npm run build` 的 Vue/TypeScript 检查与 Vite 构建通过。
`npm test -- --workers=2` 共 17 项 Playwright 用例通过，测试服务自动退出：

- 原有 8 项工作台用例保持通过。
- 新增 9 项覆盖无文档学校助手与授权参数、后台问答轮询、历史恢复及引用、跨项目迟到响应隔离、消息分页、文档操作、学校连接与附件导入、提醒已读、学期配置、移动布局及登录过期。
- 已查看桌面工作台、学校事务与手机课表截图。
- Playwright 使用 Vite 的进程内启动/关闭接口，避免当前 Windows 环境找不到 taskkill 时测试服务无法退出；若复用用户已有开发服务，不会关闭该服务。

所有浏览器测试使用模拟 API，不向真实学校发送请求，不调用付费模型，不写业务数据。
本次没有把模拟浏览器测试表述为真实学校或模型全流程验收。

## 使用

后端运行在本机 8000 端口时，在 `frontend` 目录执行 `npm run dev`。
进入研究项目可看到“历史与任务”和“学校助手”，左侧可进入“学校事务”和“我的课表”。
详见 [前端说明](../frontend/README.md) 与 [学校操作和课表接口](school-actions-calendar.md)。
