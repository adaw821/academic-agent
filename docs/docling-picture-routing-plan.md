## 当前路由规则（2026-10-09 收紧 VLM）

- 直接 VLM：图表、表格、流程图、工程图和地图，且分类置信度 >= 0.90。
- 照片、截图、整页图片、other 和未知类型先走 RapidOCR，不再仅凭类别直接调用 VLM。
- 非空 OCR 且平均置信度 >= 0.90：直接保留 OCR，包括长文本，不调用 Surya。
- 文字量 <= 5：非空且 OCR 平均置信度 >= 0.80 时保留；否则仅分类置信度 >= 0.90 的结构图、截图或整页图片进入 VLM，其余跳过。
- 文字量 > 5：OCR 平均置信度 < 0.80 才直接进入 VLM；其余短文本保留 OCR，超过 20 个文字单位且置信度 < 0.90 的文本批量通过 Surya 判断，bad 才进入 VLM。
- 权衡：无文字照片和低置信度、低文字量图片可能不再生成描述；高置信度长文本不再进行第二次质量检查。skip 保留图片节点，但不添加检索描述。
- `picture_routes` 日志记录 OCR/VLM/skip 数量；独立阶段计时区分模型加载、OCR、质量检查和 VLM 等待。

以下为原始方案示意，阈值与兜底行为以以上规则及代码为准。
